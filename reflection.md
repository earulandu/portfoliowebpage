About AI as a tool:
I think the capabilities and the skills that ai has are the most surprising. Being able to build an entire web page with just a few prompts and tweaks was shocking. When I was trying to build a website 2 years ago it took days and endless back and forth between web chats, and coding agents like cursor. But not with claude code I can get it done very quickly in one go. It was extremely good at making the base website and frame for all of the content, but i had to request changes for style and input the correct information.
	For IA2 i had a solid background of coding so there it wasn't much of a challenge for me. However, I understand the struggles of learning how to code and spending hours on a problem that would be extremely easy for an AI to fix. During my undergrad, ai was not as good as it is now so i had to resort to finding old stack exchange posts that would detail the problems and solutions. This was extremely beneficial to my learning as I still had to spend time learning about the topics and writing it myself (even if it was just copying it over). Using AI for a task this big is extremely useful because it allows users like myself (with little to no website coding experience) to make full webpages without the need to hire someone or learn all of the material beforehand. 
	The main skill/ability that AI didn't have was creative direction and overall big picture thinking. It first spit out something that was very clearly ai and was overly stylized and “AI slop”. I decided to go for a more minimalistic look with a simple and clean webpage design. It could be viewed as too simple, but I think that it looks professional and I can always revise it at a later date.
About the process:
I primarily used one prompt to get the project going, with other small prompts to assist along the way. The prompts kept getting smaller and more specific as the project went on, reflecting the size of the changes that needed to be made. The initial building was very substantial so I prompted Claude to make a list of 50 questions to base its work off of, and that worked very well. I have used this strategy many times in the past and it has resulted in quick and efficient work with less back and forth in the long run.
	I couldn't really judge the AI code on whether it was technically good or not, I just viewed the final project as completed to my satisfaction. I think in our next project I will instead go for more questions and spend longer on the planning phase. I would like to install some skills and agents that will help as well. I have been seeing it all over social media and want to give it a try. 

About professional development:
	This experience makes me a bit skeptical of software development as a standalone career. I see the value of it, but if someone like me can create a fully functional website and deploy it to the internet in a single afternoon then I am weary for being an entry to mid level developer. There will always be a need for specialists, but if I can get this much work done with minimal technical knowledge, I am concerned for the industry as a career pathway. 
	I think knowing how to code is not as important as knowing how to prompt now. When I look at my classmates' portfolios, I am amazed at what they can all do. This is their first time doing this and they have made excellent websites without knowing how to code.
	I still maintain the idea that ai cant replace makeing new ideas and the big picture/overview of creative direction and development. It is trained on data so if you want to create something new, there wont be any data on it. I think that there will also be large desire for products that do not have any AI input in the future so I am looking into that as well.
